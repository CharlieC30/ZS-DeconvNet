# Raw_Data

This directory holds raw input data for the ZS-DeconvNet pipeline. Most contents are not tracked by git due to size.

## Subdirectories

### upstream_demo/

Sample raw data and PSFs released by the original ZS-DeconvNet authors.

Download from Zenodo: [DOI 10.5281/zenodo.7261163](https://doi.org/10.5281/zenodo.7261163)

Available datasets include 2D / 3D microscopy stacks and time-lapse data. Contents are gitignored due to size.

### lab_data/

Lab-internal experimental data used for fork-specific training runs. Not tracked by git. Lab members can access via internal NAS; refer to lab documentation for paths.

### examples/

Public-facing example data that lets first-time users try the pipeline end-to-end. Currently a placeholder; intended to contain a small dataset plus a demo PSF and run script.
