### Conda Environment Setup

This directory contains pre-configured Conda environment files for ZS-DeconvNet.

### Create Environment from YAML
For TensorFlow:
```bash
conda env create -f Conda_env/zs-deconvnet_environment.yml
```

For PyTorch:
```bash
conda env create -f Conda_env/zs-deconvnet_pytorch_environment.yml
```
